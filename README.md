# HoloGuide

**AI-powered indoor navigation and event guidance platform designed to help visitors navigate large venues through interactive maps and conversational assistance.**

🏆 **5th Place — World Cup Solutions Innovation Hackathon**  
🔗 **Live Demo:** https://hologuideksa.vercel.app/

---

## Overview

Large events and crowded venues can be difficult to navigate, especially when visitors need to quickly locate entrances, halls, services, restaurants, or other points of interest.

**HoloGuide** was developed as a smart event-navigation solution that combines an interactive venue map with AI-assisted guidance to help visitors understand where they are, find their destination, and receive contextual directions.

The project was developed for the **World Cup Solutions Innovation Hackathon**, where it achieved **5th Place**.

---

## Key Features

- 🗺️ **Interactive Venue Map** — Visualizes important locations and points of interest across the venue.
- 📍 **Location-Based Guidance** — Helps users navigate from their current position toward a selected destination.
- 💬 **Conversational Assistant** — Allows visitors to ask questions about locations and receive contextual guidance.
- 🔊 **Voice Interaction** — Supports voice-based interaction for a more natural navigation experience.
- 🏟️ **Event-Oriented Experience** — Designed around the navigation needs of visitors in large events and venues.

---

## How It Works

A typical user journey:

1. The visitor accesses HoloGuide from the event venue.
2. Their current location is represented on the venue map.
3. The visitor selects a destination or asks the assistant where they want to go.
4. HoloGuide processes the request and provides relevant guidance.
5. Navigation information is presented through the interactive interface.
